# Syarat & Ketentuan Layanan tokoweb.id

Berlaku untuk semua klien tokoweb.id. Dilampirkan saat closing, dianggap disetujui saat pembayaran setup diterima.

## 1. Layanan

- tokoweb.id membuatkan, menayangkan, dan memelihara website untuk usaha Anda sesuai paket yang dipilih (Basic / Pro).
- Website tayang paling lambat **3 hari kerja** setelah data usaha (form intake) lengkap kami terima.
- Alamat website: subdomain `namausaha.tokoweb.id` (Basic) atau domain milik Anda (Pro).

## 2. Biaya & pembayaran

- Biaya setup dibayar **sekali di awal**; biaya langganan dibayar **per bulan**, jatuh tempo pada tanggal yang sama dengan tanggal website tayang.
- Pembayaran via QRIS. Konfirmasi pembayaran dikirim via WhatsApp.
- Harga langganan tidak naik selama langganan berjalan tanpa pemberitahuan minimal 30 hari sebelumnya.

## 3. Garansi uang kembali (refund)

- Dalam **7 hari** sejak pembayaran setup, jika Anda tidak puas dengan alasan apa pun: uang setup kembali **100%**, website dibatalkan.
- Setelah 7 hari, biaya setup tidak dapat dikembalikan. Biaya langganan bulan berjalan tidak dapat dikembalikan.

## 4. Keterlambatan pembayaran

- Jatuh tempo terlewat: website **tetap tayang normal selama 7 hari** (masa tenggang) — pengingat dikirim via WhatsApp.
- Hari ke-7 belum dibayar: website **dinonaktifkan sementara** (pengunjung melihat halaman "sementara nonaktif").
- Bayar kapan pun setelah itu → website aktif kembali **hari itu juga**, tanpa biaya setup ulang.
- 90 hari sejak jatuh tempo belum ada pembayaran: data diarsipkan dan layanan berakhir. Sebelum diarsipkan, Anda berhak meminta salinan konten (teks + foto).

## 5. Kepemilikan konten & data

- **Semua konten milik Anda**: nama usaha, teks, foto, daftar menu, testimoni. Kapan pun berhenti, Anda berhak meminta salinan lengkap (JSON + foto) tanpa biaya.
- Kode, desain tema, dan sistem tokoweb.id tetap milik tokoweb.id.
- Statistik pengunjung dikumpulkan **tanpa cookie dan tanpa data pribadi pengunjung** — hanya angka agregat (jumlah kunjungan, klik WhatsApp, dsb).

## 6. Tanggung jawab konten

- Anda menjamin konten yang diberikan (foto, teks, merek) adalah milik Anda atau Anda berhak menggunakannya.
- tokoweb.id berhak menolak/menghapus konten yang melanggar hukum (produk ilegal, pelanggaran hak cipta, dsb).

## 7. Berhenti berlangganan

- Berhenti kapan saja tanpa penalti — cukup kabari via WhatsApp sebelum jatuh tempo berikutnya.
- Tidak ada kontrak jangka panjang, tidak ada biaya pemutusan.

## 8. Batas layanan

- tokoweb.id menargetkan website selalu dapat diakses, namun tidak menjamin bebas gangguan 100% (pemeliharaan, gangguan jaringan pihak ketiga).
- Kerugian tidak langsung akibat gangguan bukan tanggung jawab tokoweb.id. Kompensasi maksimal = biaya langganan 1 bulan.
